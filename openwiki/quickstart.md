# Quickstart

Welcome to the **CraftMatch Verification Portal** repository wiki. This repository contains the verification and administration portal frontend for the CraftMatch platform. 

This portal is a React single-page application (SPA) built with Vite, TypeScript, and TailwindCSS. It provides administration surfaces for managing users, reviews, verification requests, and service categories.

## Scope of this Wiki
This wiki documents **only** the `CraftMatch_Verification_Portal` repository. It focuses on the web UI layout, client-side routing, React components, state, validation logic, and development workflows. For platform-wide flows, backend API details, or database schemas, please refer to the shared [CraftMatch Docs](file:///c:/Users/user/Downloads/FinalYearProject/CraftMatch_Docs/generated-wiki-index.md).
